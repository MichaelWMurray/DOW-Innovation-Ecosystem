# Funding treemap

[Open Funding treemap](https://michaelwmurray.github.io/DOW-Innovation-Ecosystem/treemap/)

The [shared hierarchy application](../hierarchy/) powers both the funding treemap and nested circles. The [published entry page](../../docs/treemap/index.html) selects this view.

OSC includes the $1,500M credit subsidy appropriation plus selected RDT&E when lending authority is off. APFIT uses the $1,355.5M FY2026 reported procurement spend plan, comprising $325.5M discretionary and $1,030M mandatory reconciliation funding. The complete spend-plan figure has not been reconciled to a single-year enacted appropriation total.

APFIT source: [FY2027 OSD Procurement justification, Volume 1–12](https://comptroller.war.gov/Portals/45/Documents/defbudget/FY2027/budget_justification/pdfs/02_Procurement/PROC_OSD_PB_2027.pdf).
